# 🧠 Forecasting & Predictive Analytics Projects

## 🇬🇧 Forecasting Great Britain's System Operator Generation Outputs

### 2009 to 2026 National Electricity Generation Forecasting

**Python • Machine Learning • Deep Learning • Multivariate Time Series • Feature Engineering • Streamlit • Render**

Developed a multivariate time-series forecasting framework using historical Great Britain electricity generation data from the NESO Data Portal.

The study uses approximately **16 years of half-hourly operational generation data** to model:

- Seasonal generation behaviour
- Intraday demand and generation ramps
- Fuel-mix relationships
- Long-term generation trends
- Future electricity generation output

The deployed system supports both:

**Forecasting**, for estimating future generation output.

**Hindcasting**, for performing offline inference on historical time steps and analysing model residual errors.
