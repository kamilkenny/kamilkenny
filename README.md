# 🚀 Featured Data Engineering Projects

### 🚆 Greater Manchester Transport Intelligence Platform

**Python • Azure SQL • Microsoft Fabric • OneLake • FastAPI • GitHub Actions • Azure App Service**

End-to-end public transport data engineering platform that automates TfGM GTFS ingestion, source preservation, validation, dimensional modelling and cloud delivery of route, stop, operator and network intelligence across millions of timetable records.

🔗 [Repository](https://github.com/kamilkenny/greater-manchester-transport-data-platform)  
🌐 [Live Platform](https://gm-transport-intelligence-kamil.azurewebsites.net/)

---

### 🌊 Greater Manchester Flood & River Monitoring Platform

**Python • SQL Server • Azure SQL • T-SQL • SSIS • SSRS • Visual Studio**

Enterprise-style ETL and reporting platform using Environment Agency data to monitor river levels and flood warnings through staging pipelines, dimensional modelling, data-quality validation, SQL procedures, audit logging and reporting.

🔗 [Repository](https://github.com/kamilkenny/greater-manchester-flood-monitoring-data-platform)

---

### ⚡ Great Britain Generation Availability Intelligence Platform

**Python • PySpark • Databricks • Delta Lake • Unity Catalog • PostgreSQL • Power BI • Azure**

Cloud data engineering platform that automates ingestion and preservation of NESO/Elexon generation availability publications and produces fuel, system and generating-unit revision intelligence.

🔗 [Repository](https://github.com/kamilkenny/GB-generation-availability-intelligence-platform)  
🌐 [Live Platform](https://gb-generation-intelligence-kamil.azurewebsites.net/)

---

### 🔌 GB Grid Congestion & Constraint Cost Intelligence Hub

**Azure SQL • Python • Flask • Machine Learning • GitHub Actions • Azure App Service**

Integrated NESO congestion, constraint cost and network datasets to analyse grid stress, high-cost events and system risk using automated cloud pipelines and predictive analytics.

🌐 [Live Platform](https://gb-grid-congestion-kamil-898341.azurewebsites.net/)

---

### 🌬️ GB Wind Forecast Revision Monitor

**Python • PostgreSQL • GitHub Actions • Streamlit**

Automated collection and monitoring of Great Britain's 14-day wind generation forecasts, enabling analysis of forecast revisions and changing system expectations.

🌐 [Live Dashboard](https://neso-wind-forecast-monitor-knbc32cgs89awbzxdfujqi.streamlit.app/)

---

### ☀️ Hybrid Power Generation Forecasting Platform

**Python • TensorFlow • BiLSTM • Informer • Streamlit • Time-Series Forecasting**

Developed a deep-learning forecasting system using six years of PV generation and meteorological data for a 39.02 kWp hybrid PV-grid system, delivering multi-step forecasts through a real-time web application.

🔗 [Repository](https://github.com/kamilkenny/EDA)  
🌐 [Live Application](https://kamil-deployment-of-edgehill-durning.onrender.com/)
